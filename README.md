---

## What is this?

This repo is where I track my progress working through coding interview problems. Solutions are synced here automatically via NeetCode's **GitHub Sync** feature, but the goal of this repo is simple: keep a running history of what I've solved, revisit old attempts, and see how my solutions improve over time.

---

## How it stays in sync

1. My GitHub account is connected via [neetcode.io/profile/github](https://neetcode.io/profile/github).
2. Every time I submit a solution on NeetCode, it gets pushed here automatically.
3. Past solutions can be bulk-synced, and individual submissions can be synced or removed manually from the submission history panel.

---

## Repository structure

Solutions are organized by topic folder, then problem ID. Each submission is stored as a separate file:

```
<topic-folder>/
  <problem-id>/
    submission-0.<ext>   ← first submission
    submission-1.<ext>   ← second submission
    ...
```

**Example:**
```
Data Structures & Algorithms/two-integer-sum/submission-0.py
Data Structures & Algorithms/binary-search/submission-0.ts
Python For Beginners/python-hello-world/submission-0.py
```

Keeping every submission (not just the latest) makes it easy to look back and see how a solution evolved across attempts.
